# Yacht Royale requirements
# Note: This is a JavaScript/TypeScript project (not Python).

[Runtime]
Node.js >= 20.x
npm >= 10.x

[Platform]
Web browser with modern ES module support

[Required npm dependencies]
react@^19.2.7
react-dom@^19.2.7
firebase@^12.16.0

[Required dev dependencies]
typescript@~6.0.2
vite@^8.1.1
vitest@^4.1.10
@vitejs/plugin-react@^6.0.3
oxlint@^1.71.0
@types/node@^24.13.2
@types/react@^19.2.17
@types/react-dom@^19.2.3

[Online multiplayer setup]
Create a .env file from .env.example and set:
VITE_FIREBASE_API_KEY
VITE_FIREBASE_AUTH_DOMAIN
VITE_FIREBASE_PROJECT_ID
VITE_FIREBASE_APP_ID

[Commands]
npm install
npm run game
npm run verify
